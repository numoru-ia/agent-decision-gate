# Bench results: 2026-11-22

**Synthetic data on one laptop. These are not claims about any vendor's model.**

- Machine: Apple M3 Pro laptop, macOS, Go 1.27.4, single process, no network.
- Data: `examples/*/synthetic-*.jsonl`, generated by `go run ./examples/gen` (seed 20261122). No customer data.
- Latency is in-process time per decision (feature extraction + scoring). It excludes any network hop, which is what dominates a hosted API.
- `llm` and `http` rows are absent on purpose: this machine had no API key. See the README for how to run them.
- The tickets `rules.json` was written by the same person who wrote the dataset and knew every base phrasing, including the test ones. Read the rules row as an optimistic keyword baseline.
- The tool-gating test set has 12 examples. Treat it as a demonstration, not a measurement.
- In `gate(...)` rows, a decision escalated to a human counts as not automated. `coverage` is the share decided automatically and `acc` is accuracy on that share. The accuracy and macro-F1 columns count human escalations as misses, so they understate a gate. Read coverage and acc instead.

Commands:

```sh
go build -o bin/decide ./cmd/decide
bin/decide train -data examples/tickets-es/synthetic-train.jsonl -out models/tickets-logreg.gz
bin/decide train -data examples/tickets-es/synthetic-train.jsonl -algo nb -out models/tickets-nb.gz
bin/decide train -data examples/tool-gating/synthetic-train.jsonl -out models/tool-gating-logreg.gz
bin/decide bench -question examples/tickets-es/question.json -test examples/tickets-es/synthetic-test.jsonl \
  -backends "rules=examples/tickets-es/rules.json,local=models/tickets-logreg.gz,local=models/tickets-nb.gz" \
  -gate "local=models/tickets-logreg.gz@0.6" \
  -gate "rules=examples/tickets-es/rules.json@0.99,local=models/tickets-logreg.gz@0.6" -threshold 0.6
bin/decide bench -question examples/tool-gating/question.json -test examples/tool-gating/synthetic-test.jsonl \
  -backends "rules=examples/tool-gating/rules.json,local=models/tool-gating-logreg.gz" \
  -gate "rules=examples/tool-gating/rules.json@0.99,local=models/tool-gating-logreg.gz@0.8" -threshold 0.6
```

Microsecond latencies vary by a few µs between runs. Accuracy figures are deterministic.
